最近几周自己比较闲，于是打算折腾各种 Agent 玩具，让假期的时间显得不那么*unemployed*。从年初开始，各种 Agents 层出不穷，无论是代码开发（cc/codex），日常事务（claw，hermes）还是生活（千问），只需要使用自然语言即可完成过去复杂的编码、code review 和各种消耗热量的任务，这使得一些工作流可以在缺乏环境的情况下进行。当你发现即使出门在外，用几句话就可以完成某个 ECS 的脚本配置和重启操作，你会马上忘记那些打开 Tailscale 再连 SSH，用 5 寸触摸屏艰难运维的时光。

![image](./will-apps-be-replaced-in-the-future/self_execution.png "可惜，它紫砂了")

既然整理邮件、操作终端、连接 Git 或者 Notion 这类功能都可以收敛到同一个聊天上下文，那么随着 Agent 能力的提升，AGI 时代的到来（并不），是否可以透过一个巨型网关，使用各种 API 或通用套件，自由创造可自定义的服务？它会显著缩短缩短的开发周期、减少前后端交流成本，更重要的是给予了所有人自由构建 UI 的能力。你可以像自定义窗口排布一样自定义应用界面，展示 Obsidian 上某次旅行的计划表，同时显示当前位置与天气、Google Maps 上的交通路况，旁边放上直播大屏，或者创作一个极简的 Dummy Discord，丢掉花哨的一辈子也不会用到的各种功能。就像曾经兴起的低代码平台，但是更简单，更自由，更强大。

不过，门槛的降低也会导致软件质量的降低，极大的自由度会带来一个野蛮生长的时代。或许很少有人会着手构建统一风格的用户界面，会把心思放在对齐几个像素或者微调按钮折射效果上。总之，这只是一个寒假没有什么事情做的人的奇思妙想罢了。
